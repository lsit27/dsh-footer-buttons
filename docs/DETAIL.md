# 侧栏按钮布局

一个纯前端插件，专门整理 DSH Web 界面左侧栏底部的插件按钮。当 `dsh-restart`、
`dsh-redteam-mode`、`dsh-plugin-session-purge` 等插件都把按钮注入同一个
`sidebar.footer.action` 槽位时，宿主的单行 flex 容器会把它们挤在一起、高度参差，
文字甚至会被压成竖排。本插件把这些按钮统一成清爽的一列。

## 功能

- **竖向排列**：每个按钮独占一行，不再横向挤压。
- **左对齐**：图标与文字靠左，符合侧栏的阅读习惯。
- **宽度自适应**：按钮按自身内容收缩，不强行撑满整行。
- **高度统一**：所有按钮拉齐到 30px。
- **隐藏 / 恢复**：底部「更多」面板列出所有按钮，点击即可隐藏；隐藏后可从同一面板恢复。
- **状态持久化**：隐藏状态存于浏览器 localStorage，刷新页面后保持。

## 使用方法

1. 安装并启用本插件，刷新 Web 页面。
2. 侧栏底部的按钮变为竖排、左对齐、宽度自适应。
3. 点击底部的「更多」，在面板里选择某个按钮可将其隐藏（「更多」会显示隐藏数量）。
4. 再次打开「更多」，该按钮显示「显示」，点击即可放回。

## 工作原理

插件只在浏览器端工作：

- 通过一段注入 `<style>` 的 CSS，命中 `[data-slot='sidebar.footer.action']` 容器及其中的按钮，
  设置 `flex-direction: column`、统一高度与对齐方式。
- 通过 `ctx.slots.register` 在同一槽位末尾放一个「更多」面板组件。面板打开时读取该槽位里
  已渲染的按钮列表，隐藏按钮时只设置其 `style.display = 'none'`，不移动 DOM 节点，
  因此不会干扰各按钮插件自己的 React 渲染与点击事件。
- 隐藏状态以按钮的可读标识（aria-label / title / 文本）为键存入 localStorage。

## 兼容性

- 仅影响 `sidebar.footer.action` 槽位，不改变其它 UI 区域。
- 不修改、不依赖任何其它插件；按钮插件可独立安装、卸载。
- Host 半侧为空，无 HTTP 路由、无服务端状态。
